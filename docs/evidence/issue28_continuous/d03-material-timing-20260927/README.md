The original test prepares source and a simulated model request once each; packet **record** builds and authenticates the same candidate twice, and independent packet **replay** also builds and authenticates it twice. The repair lets `validate_candidate_response()` build and authenticate one request, then optionally return that exact request together with its checked result. Existing callers with an explicit request still receive the same result shape and must match the rebuilt request. `record_offline_response()` snapshots its in-memory source/request and authenticates once before writing exact bytes; it rejects mutation of the caller inputs. `replay_offline_response()` authenticates independently once from disk, compares the saved candidate request, and still checks every packet file, identity, raw response, unresolved status and tampering. No previously computed source check is trusted across record and cold replay.
