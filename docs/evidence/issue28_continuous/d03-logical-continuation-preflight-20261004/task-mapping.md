This is a new source-responsibility input mechanism, not a third response to
the ended eight-location context-request trial. No new model answer or semantic

## Actual responsibility and context

Every original visible block, full native fact wrapper and outer supplement root
has its original unit/kind/index locator. Native chains attach complete original
roots; five fact-footnote relationships bring in their exact linked facts and
footnotes. These literal dependencies reach a fixed point even in reverse source
order. Responsibility is assigned exactly once; other tasks can share its context.

All visible text and quotation-context flags are delivered to every task.
Raw-span coordinates/digests remain in the unchanged source identified by the
external source hash; they are not replaced by invented model coordinates.
Native views are explicitly PARTIAL views referring to parent source units,
never complete units with altered payloads under an old unit_id. The existing
lossless namespace/context/unit/style/row codec is reused and inverted exactly.
Actual source-native wrappers, raw XML, tables, headers and footnotes are retained.
The original source, old model responses, native pending objects and runtime
Requirement bindings are not modified or rebound.

The draft output asks for relevant findings plus specific unresolved items,
not one background classification for every numeric fact. Findings must cite
owned responsibility, with shared context permitted. Accounting context dates
must not be substituted for investigation event dates. This defines the proposed
development task; no model has yet demonstrated that it follows these instructions,
and no new response acceptance/native company path is wired here.
