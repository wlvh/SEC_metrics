# Salesforce B03：原件金额构成的有界核对

`census.py`从 #28 已认证的 Salesforce FY2026 同次申报主年报和 Company Facts 读取折旧、摊销及减值相关原生事实。它只证明所列事实、期间、主体、来源字节与现金流量表脚注的关系；不创建 Result/Run，也不恢复此前已撤回的 B03 当前信用。输出见 `census.json` 与 `census.log`。

现金流量表的完整折旧摊销行包括无形资产摊销、固定资产折旧，以及使用权资产摊销**和减值**。`census.json`保留这句及两份金额脚注在主年报中的原始字节跨度和SHA，并核对同期间原生事实与Company Facts。已报告的固定资产 12 亿美元与收购无形资产 17 亿美元，原生精度均为`decimals=-8`，不是精确到美元的组成金额；另有融资租赁使用权资产摊销 3.75 亿美元，但现有原件并未把这三项证明为完整且互斥的现金流行分解。本次同申报、同期间原生事实扫描未找到单列的使用权资产减值金额。这个有限的无命中不证明全文没有任何其他说明，更不能把 36.31 亿与几项金额的差额改称减值金额。

因此，已保存来源中的这些事实仍不足以建立**精确、无减值的完整折旧摊销额**。Salesforce B03 继续具体扣留为来源范围未决；后续只能寻找有依据的精确组成关系或按既有业务修订机制决定处理方式，不能直接取较大的现金流行或按舍入差额猜扣。真实 provider/paid/SEC 调用 0/0/0，#47 与生产入口未操作。
