# D03: preserve a complete but uncertain per-request assessment

The D03 full-source parser accepts an answer that reviews every supplied unit and explicitly leaves an action, subject or period unresolved. The recorded native acceptor previously raised `D03_SOURCE_ASSESSMENT_UNRESOLVED` after that check, so the controller saved a `FAILED_TERMINAL` without Candidate/Evidence. The company collector then counted that group as missing. This conflated a valid uncertain assessment with an incomplete or malformed response. It also prevented a future whole-company Review from seeing the uncertainty.

The current D03-only acceptance branch retains source-valid uncertainty in `OBSERVATION_CANDIDATE.unresolved_competing_claims` and an explicit `EVIDENCE_CHECK` check. That check means the response shape, source references and preservation were verified; it does **not** approve the model's interpretation. The recorded collector cold-replays the request and response, recomputes the blockers from the raw answer, identifies each unresolved request, and returns `UNRESOLVED_REQUIRES_NATIVE_REVIEW` when all groups are present but some remain undecided. Missing or failed groups still have an incomplete branch. B13/D04 retain their existing unresolved rejection. Resolved D03 responses keep the original record shape, and their directed replay still passes.
