经用户明确批准且完成受限恢复/同摘要许可的实现、正反测试、限定独审与最终禁网接线后：只用原账本、原deepseek-flash/Chat Completions/单请求资源限制；113与114各最多一次新执行机会，按申领而非成功消费；其余14组只能按`current-request-identity.json`列明的新业务摘要执行，全部共最多16组。旧失败及所有计数不改，零自动重试，不从响应失败自动再抽。若某公司单组内容失败，停止该公司受影响路线，继续仍合法且无共同正确性风险的另一公司；若出现402、未知远端结果、来源真实性或用量不明，则停止对应通道并保留原件，不继续申领。服务是否可用不能靠账户猜测或探针替代真实授权后的首个请求结果。

Enphase先完成6组，再完成Paramount10组；**验收单位是完整公司**：每组必评来源和完整正文保留，原生接受无未决，形成该公司完整Result/Run、公开格式行、保存包及独立冷读通过。可以形成有依据的不同披露结论，不能预设必须与既有八家同为“无疑虑”。单条请求成功不计公司完成。结果仍为私有候选，不切实际active、不Ready、不合并、不采纳或部署。若组数、来源或口径改变，先重计量并重新判断授权范围。
