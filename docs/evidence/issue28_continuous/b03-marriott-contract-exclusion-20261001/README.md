原 #28 已认证 Marriott FY2025 10-K 主HTML提供同期间、同主体、美元的145,000,000折旧和313,000,000无形资产摊销，与所选Company Facts两项逐项一致。另一类正数合同成本摊销的合并事实为135,000,000美元，另有四项带营业分部维度的83/19/1/6百万美元。程序没有把分部事实当成新的合并加回额，也不要求不完整的分部和等于合并值；任意不同维度或超出合并额的分部集合继续阻断。
