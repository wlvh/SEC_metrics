# 组合附注中的借款账面金额核对

本增量解决 Pfizer B06 当前遇到的组合附注、多张表和账面调整结构。运行器使用实际来源发现和解析金额，没有按公司保存答案。它仍是未接入原生 Run 的来源组件：已证明的借款小计不代表完整 B06，融资租赁及完整债务遗漏清单尚须继续处理。

## 实际证明

使用已准入的 2025 年报 HTML、同次申报 XML、Company Facts，以及原始清单和目录索引。官方概念命名空间、货币单位、主体、期间和原文显示位置均参与核对。

| 项目 | 原报告账面金额（USD） | 组成关系 |
|---|---:|---|
| 短期借款 | 3,154,000,000 | 表中本金合计及其实际报告的调整项，与原生事实一致 |
| 非流动长期债务 | 61,641,000,000 | 本金、公允价值调整、未摊销项目相加，与原生事实一致 |
| 其中一年内到期的长期债务 | 2,997,000,000 | 包含在短期借款中；长期表明确列在其非流动合计之外，不再次相加 |
| 借款小计 | 64,795,000,000 | 只将上述短期账面总额与非流动账面总额相加 |

正文同时把长期债务概述为 62 billion；保留这一较粗报告，按其原始 `decimals=-9` 与 61.641 billion 核对，不能覆盖精度更高的表中金额。

长期债券明细加总为 61.294 billion，原表本金合计为 61.293 billion。组件保留差额，以同一报告会计政策附注明确的四舍五入说明和各单元格显示精度检查可容许区间，不改写明细或合计。跨 HTML/XML 的金额对应仍使用原生报告精度；这种容差不用于掩盖来源不一致。

## 从真实前期来源纠正的假设

已保存的 2024 XML 在短期借款表额外报告公允价值调整行，并有短期本金和账面数的舍入差异。2025 的简化等式“当前长期债务账面额＋其他短期本金＋商业票据本金＝短期借款账面额”并非通用规则：发行成本也可能影响其他短期债务。

当前实现按每张表实际报告的本金及调整项核对各自账面总额，允许明确出现的短期公允价值调整行；不要求人为将整表发行成本归属某一种债务。原 2024 HTML 未保存，因此这里只完成真实 XML 表结构检查，没有宣称完整跨年输入重放或新年度运行通过。
