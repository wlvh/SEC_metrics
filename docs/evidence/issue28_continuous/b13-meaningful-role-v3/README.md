# B13 有含义角色标签 V3：离线候选，禁止真实申领

原 170 的类别码与其解释、来源不符，且 110 条发现中有 46 组完全重复；原 111 使用完整类别名称时也曾把制造设施利用率误归到产品能力。因此数字编码可能增加映射负担，但不是已证明的唯一原因。旧 V2 提示已要求不重复，继续加一句同义提醒没有独立证据。此增量选择一个明确、可测的请求表达候选：仅把紧凑响应的**类别数字**改为有含义的角色标签，主体、期间及 B/F/S 引用继续用原紧凑表示；附加两类观察到的边界说明——实体的融资／股权／税务等“计划”不是未来物理产能，存货成本分摊用的设施利用率不是产品储能／装机容量；要求每个不同发现只出现一次。原类别定义、来源单元、必评集合、4096 输出上限和历史请求均不改。

`B13_MEANINGFUL_ROLE_REFERENCES_V3`只能显式选取；默认 V1/V2 选择及旧请求重读保持原样。新增真实执行的申领前阻断 `B13_ROLE_V3_LIVE_VALIDATION_NOT_AUTHORIZED`，即使将来 171 服务停止获得处理，也不能凭新摘要直接购买 111／170 的替代回答。V3 是**修后验证候选**，并非已批准的真实请求或已证明能提升模型准确率的实现。

离线正反验证：39 项定向测试通过，126 项 fast suite 通过（52.735 秒）。实际 Enphase 保存来源仍完整分为 6 组，每组原单元及必评集合逐项相同；最大输入 187528 token，仍留原 4096 输出预留。把原 170 的 110 条错误／重复输出只作机械标签替换，计 3230 token、仍因重复被拒；这证明表达成本可容纳原样样本，不证明未来完整正确回答必能装下。原 111 的 V1 请求可按原字节重建，当前语义复验仍有 1 项未决。禁网录制 factory/opener/controller 对 V3 空必评组返回成功，对原 111 返回失败；空组对照不代表非空公司结果。证据见 `offline-candidate-summary.json`、`role-short-wiring-summary.json`、各自脚本与日志；实际执行权限和新接线收据校验见 `final-wiring-validation.json`。

原 `ec311e2d` 的两项 P2 已由用户转交的[外部限定复核](../b13-170-source-audit/external-limited-p2-ec311e2d.md)结案，原子代理的发现记录不改。**V3 补丁 `78779bf34ccae4ea076f391e790c264f6eebd964` 的新差异仍待限定复核**；此次父会话测试不是独审。原 111／170 的账本终态及 113／114 的历史失败均未改写。
