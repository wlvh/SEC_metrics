## 实际新增能力

`d03_context_requests.resolve_context_requests` 从调用方已经认证的完整 D03 Source 读取指定上下文。调用方提供外部 source SHA 和当前请求的责任单元集合；每项请求必须有该集合内的原始引用。目标仅为同一文档中的明确 XML id，或明确的连续正文块区间。既有原始单元、原始元素、位置、字典和 XML 字节保留；嵌套元素核对相对字符切片及父 XML 摘要，正文不摘要、不跨缺块拼接。

原必需单元集合不改变，上下文不伪装成新责任单元。定位不存在、id 歧义、块数或累计字节超限分别保留原请求和具体未决原因，不猜位置、不截断原文。默认一次最多8项请求、每个正文范围32块、累计上下文262144字节。这是本机械接口的有限参数，**不是公司任务总次数、模型资源测量或真实调用许可**。没有自动递归扩展所有 XML 关系。

`replay_context_packet` 用外部 Source/packet 摘要再次从原 Source 定位，逐字节重建 packet；重新计算一个被篡改 packet 的摘要也不能逃过与原件的重建比较。该接口没有 SEC 获取、模型传输、账本申领、SYSTEM/HUMAN 批准、Result 或 Run 功能。
