## 已实现及实际验证

新capture入口只接受十公司范围内已发现的具体来源依赖。已有可验证原件直接复用，元数据刷新另留父日志身份；原件不得原样重抽。真实路径使用原SecHttpClient、原官方SEC边界、60秒HTTP超时与max_retries=0，保留原日志字节前缀、不可变body/headers与当前执行规则。统一CallLedger按固定目录累计SEC槽，不因公司、阶段或输出目录归零。失败与未知调用计账，UNKNOWN/402暂停受影响通道。

获取检查记录由实际创建进程登记在安装目录acquired分支。测试路径只调用已有持久化原语，完全没有网络出口，也不替换进程全局live transport。记录模式、调用数和原始请求行相互绑定；导入sidecar不能自行登记或将测试改标live。失败URL保留原行但不授来源信用，其他成功原件仍可被正常读取。新获取信用仅属于当前结果真正选中的新请求，旧输入不会因为同一日志里增加了新行就被升级。
