# Ten-company source discovery with old semantic producers disabled

This checks whether the **source-discovery step** of ordinary updating still works when all 116 retired semantic producer exports are unavailable. `check.py` uses the existing #28 cumulative saved-source root and current product code at `76ebe42e`. It invokes `inspect_source_requirements` for the configured ten companies under the same old-producer disablement used in the prior Marriott normal-Run checks. Socket, DNS and SEC HTTP access are blocked; original claims, source request log and active pointer hashes are checked before and after.

`run.exit=0`, `run.log` and `result.json` show all ten returned `SAVED_SOURCE_DEPENDENCIES_AVAILABLE`. The result retains each company's requirement count and exact metadata refresh URLs: **29** in total (two for eight companies, three for Paramount, ten for JPMorgan). Five prior primary URLs are not directly saved but the existing discovery result recognizes verified same-filing native alternatives, so those are **not** recorded as unresolved new GETs. The 29 refresh addresses are future discovery checks, not calls made here or blanket permission to fetch. This run used **0/0/0 real provider/paid/SEC calls** and changed none of the three original protected files.

`run-aborted.log` retains a first interrupted attempt. While it was still computing, source inspection showed that the evidence script was incorrectly about to read per-requirement `status`; the actual fields are `saved_status` and `refresh_for_new_discovery`. That first attempt was deliberately stopped with Ctrl-C before producing a result and is not counted as a failed product discovery or a passing test. The corrected script records the actual fields, preserves a non-directly-saved item's original status and roles, and does not infer a missing source from the absence of a direct primary file when the discovery result has a verified alternative.

This is a **source-discovery and legacy-exit preparation** result only. It does not test live SEC capture, a newly arrived annual filing, interpretation, all 39 company Results, a full 390 coordinate version, or formal retirement of every old entrypoint. It does not turn metadata refresh suggestions into actual call credit or a resource request. No #47 branch, ledger, source snapshot or PR was operated.
