# 普通修订年报的有限来源证明

本增量用于解决“发现 10-K/A 就阻断全部普通指标”的程序缺口。它只证明某一种输入属性是否仍成立，不形成指标 Run，不批准生产，也不改变主体连续性规则。正式入口的接线仍待当前十公司 × 34 项固定版本诊断批次完成。

## 实际能力与边界

| 来源 | 已完成的核对 | 可以证明的属性 |
|---|---|---|
| Southwest 2025 原报告及 2026-02-06 修订 | 官方原件身份与实际期间；完整说明、原封面、实际 Item 15、变动链接及签名；只省略原件明确的页码与目录链接对 | 事件日期窗口不变；原报告财务数值未被这份修订改变。B06 债务性质不在这项证明内 |
| Paramount 2025 原报告及 2026-04-24 修订 | Part III/IV、Items 10–15、未新增财务报表声明及原生治理事实类别 | 事件日期窗口不变。原报告财务范围、前后主体合并和治理指标仍须各自验证 |

代码按原件结构、主体、日期及内容核对，不用公司名、固定 accession、年份、原件 hash 或预填答案授予语义通过。来源 hash 仅绑定原件与已保存的真实获取记录。

`prepare_saved_amendment_input` 保留每份当前修订件、原件、来源记录和完整检查结果。所有修订均须证明请求的输入属性；不支持的财务修订形成 `WITHHELD`，不会删除修订再读取旧值。日期窗口成立本身不证明事件来源齐全，也不证明原主体延续。

## Pfizer B06 后续实现依据

`pfizer-b06/source-and-note-index.json` 绑定实际 2025 原件与原生事实序号。原件包含金融工具组合附注（ordinal 1367）、短期借款表（1724）、包含两张表的长期债务附注（1740）、其他财务信息中的供应商安排（1911）及经营租赁披露（2860）。因此当前 `DebtDisclosureTextBlock` 缺失错误不能解释成公司没有披露债务。

短期借款分别列出本金、账面调整与包含当前长期债务的账面数；长期债务另列公允价值调整、未摊销项目及明确“不包括在上方”的当前部分。后续应支持这种组合附注和多表结构，核对金额计量与重复计算。不能只替换附注名称后套用旧公式，也不能因为没有独立融资租赁标签就自动填零。供应商项目按原文已报告分类核对，不扩大为合同或信用评级研究。
