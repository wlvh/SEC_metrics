## 改动

新`capacity_quantity_scope.py`复用现有可见HTML块解析器，记录真正h1–h6标题的原字节、级别和结束范围。一个标题的范围只有同级或更高层级标题才结束；低级标题、普通粗体、间隔段落不结束。引用/隐藏/目录可见性沿原解析器处理，不能把样式加粗直接当章节边界。标题结构无法解析时明确拒绝。

新显式`B13_HTML_QUANTITY_SCOPE_V1`元数据只记录原件结构和引用，不是人工提供的业务答案。现有reference-context来源入口自动重建该元数据；原可见/native/续接units及其字节/身份不删改。新source/request身份包含元数据和解释说明，原请求不补写、不借旧执行信用。请求可以恢复全部原units，最终数量/文字消费者还从原HTML独立重建并核对元数据，重签修改标题、级别或边界不能绕过。

同块`These quantities are hypothetical examples, not actual production or available capacity.`这类明确后置限定按句子字符位置仅约束其前述数量；同块后续独立实际数量仍须处理。标题与同块限定由数量提取和分类守卫共用；明确假设数量不能被标成当期ACTUAL_PRODUCTION/AVAILABLE_CAPACITY来计算。既有临近引语检查保留，但先限制在真实标题范围以内，不因前节的假设标题否认新实际章节。

旧请求无必要HTML结构时，显式年度数量产生`B13_QUANTITY_HTML_SCOPE_NOT_SUPPLIED`未决，原生接受不能通过；旧无年度数量的文字来源及68原税收抵免错误按原当前检查继续解释。不从缺元数据推断缺披露。
