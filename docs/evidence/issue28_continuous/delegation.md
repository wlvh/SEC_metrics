## 五、日常运行不产生必需人工任务

正常处理链应当自行到达明确终态：

```text
发现输入
→ 可信获取
→ 自动解析和必要解释
→ 验证与计算
→ 正常结果或有依据的非数值状态
→ 按运行政策更新并保留历史
```

不允许把以下操作设计成常态运行依赖：

```text

按公司修改代码或配置答案
```

开发独立审阅、一次性业务取舍、总预算和首次生产批准可以保留。这些项目决策不能延伸成每份财报都需要的人工作业。

自动未完成状态必须区分：

| 原因                     | 处理要求                         |
| ---------------------- | ---------------------------- |
| **公开披露确实不足或存在无法消除的冲突** | 完成规定检查后，自动形成有依据的状态，继续不受影响的任务 |
| **资料充分，但规则尚未实现**       | 作为开发责任继续处理，不能伪装成披露不足         |
| **解析、映射或验证器故障**        | 修复实现并验证，不能让用户补答案             |
| **权限、来源真实性或运行环境问题**    | 隔离受影响动作，保留状态；无依赖工作继续推进       |

旧的有效结果可以作为历史展示，必须带原期间和当前更新状态，不能冒充本期成功。

**验收同时要求：零日常必需人工操作，以及资料充分、口径适用时的真实自动完成。**零人工加大量拒绝，不满足目标。
