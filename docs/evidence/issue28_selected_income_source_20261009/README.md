# Selected filing income source interface

Fixed base: main `dae5c660e333242bb658706e3c98016c8856220f`. This explicit source-only successor lets a consumer already holding a selected filing read its original monetary facts. It never chooses the latest filing, prepares B06/current income, fetches a source, consumes a saved answer, calculates a metric or creates Candidate/Run/Result. Existing main `ordinary_income_input`, `normal_annual_input`, source authority and defaults remain byte-identical.

`selected_income_source_v1.native_income_reports(source, annual, concepts, *, check_visible_short_period=False, namespace_policy='YEAR_ONLY', annual_period_reader=None)` takes existing source/prepared-annual structures. Default annual identity is still checked from exact raw DEI bytes by the original annual reader. An explicit consumer can pass its existing, verified historical DEI reader as program code; this reader receives these exact raw bytes/CIK/filing and must return the same target period. It is not a supplied answer or new approval mechanism. The consumer must bind that reader's code and relevant configuration in its existing processing files. Source request identity/admission, amendment clearance, statement scope, completeness and Calculator decisions remain consumer responsibilities.

The native fact loop reuses the existing raw-asset/company/accession binding, annual identity, native stream count, fact subject, official FASB concept, USD unit and native context proof checks. YEAR_ONLY remains default. The copied finite `xbrl_namespace_policy` helper comes from PR67/f790; only an explicit YEAR_OR_DATE_RELEASE input accepts the historical date-form FASB namespace. This is source syntax handling, not a new metric policy. Consumer must also bind this setting, source helper and namespace helper in normal update configuration; no recursive closure/platform is introduced.

The visible-column function's AST is identical to the existing PR67 implementation. Short-period checks preserve MATCH/CONFLICT/UNRESOLVED with original headers and source references. A consumer cannot treat conflict, missing evidence, empty candidates or a source row itself as a completed metric/absence finding. Original financial scope remains independent; this utility does not clear Paramount Part III amendments or turn August7/August8 into an arbitrary chosen date.
