## 与接收方此前临时脚本的差异

临时脚本的做法有三点不同：按文件扫描原件目录，使用合成身份，并绕过了年报选择。因此：

- 它把不在注册表的 Hyatt、BAC 也算了进去，得出“Hyatt FY2025 倒退”和“14 份新可准备”。按生产入口和注册公司重跑，实际是 0 个倒退、10 个新可准备。Paramount 2024–2025 在生产路径上会先被“修订/继任”检查拒绝。
- 它把 FY2021 的失败当成脚本自身的限制。生产入口显示这是真实失败：FY2021 年报使用季度版 DEI 命名空间 `dei/2021q4`，而 D02 路径只接受年份版。只把政策传给 `build_text_document` 还不够，下游还会报 `TEXT_BUSINESS_DEI_IDENTITY_CONFLICT`。

`summary.md`、`manifest.json` 和 `comparison.json` 是工具的原样输出。`manifest.json` 中的本机路径只作线索，以哈希为准。
