4. **Part III 修订的措辞**（`part-iii-statement-review/second-instance.json`）：前身 FY2024 那份 10-K/A 的说明段措辞不在已批模式内，影响 FY2024 的 14 个位置（事件 6、报表 8）。
5. **#47 的 SEC 获取许可**：上限由 1,232 重测为 **1,352**（年报链与元数据 150、事件窗口 1,046、治理代理 36、预留 120；`acquisition-plan.json`），许可对象已由 `tools/propose_historical_allowance.py` 生成并过了真实验证器（`acquisition-wiring/proposed-allowance.json`），范围多了治理披露这一类。
6. **#47 的模型调用许可**（B13/D03/D04）：今天能测的只有 Marriott 两个往年的 18 次；其余往年要先有原件。
