`tools/prepare_c02_table_context.py` 从既有 restore 根的认证原件构建所有治理文字块，复用
`table_grid.build_table_grid` 解析全部 HTML 表格。原 `c02-model-method` 的任务正文逐字不改，

原问题是 JPMorgan FY2021 开发回答明确留下的未决：压平后的 Current Board committee
membership 表失去列对应关系，A/B 代码无法可靠归给委员会。原表 `table_000129` 是 12×21，

不能据此推出 2021 年末成员。出处、原块全文/跨度/hash 和单元格坐标在
`reference-jpmorgan-2021.json`。这是执行者的开发参考，不是独立输入试验或新接受。
原 FY2021 留出结论仍解释旧规则/旧提示；本位置已用于本次表示开发，不再是新表示的留出。

## 表示与保留范围

`strings` 前 `block_count` 项就是 B0…B<n> 的完整原文，重复块也保留其原编号。
额外字典项只存单元格/标题的文字，不是新的 B 引用。每张表保留 ID、行列数、标题及
非空或带表头属性的原点格；重复的 rowspan/colspan/header 用共享 geometry 字典表示，
每张表有默认 geometry，例外格显式覆写。空白无表头格按原坐标补空；不删表格、不筛业务词。

独立比较函数将模型视图展开，与公用解析器的每个文字/表头格比较，并将 B 文本顺序与
原文档逐项比较。四份均完全一致。此命题不是完整 raw-grid 的可逆声明：空白格的 HTML
原点元数据、entity 原拼写、样式和图像只留在原件/本地 DerivedAsset，不进入模型表示。
图像没有被阅读；文字/网格一致也不证明模型含义正确或全文所有媒介已覆盖。
