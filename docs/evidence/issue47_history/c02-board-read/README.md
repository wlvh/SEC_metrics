# C02 董事会构成：逐条判读已发布的十个值

## 结论

十个 C02 值（九家公司最新期间 + Paramount 前身 FY2024）**全部含有在任何口径下都不属于董事会构成的摘录**，已按坐标登记为内容缺陷并撤回（`../known_result_defects.json`，`C02_*_SELECTOR_ADMITS_TEXT_OUTSIDE_BOARD_COMPOSITION`）。246 条摘录逐条对照已批定义（"来源 DEF 14A；可输出董事人数、独立董事数、委员会信息"）判读：

| 类别 | 条数 | 含义 |
|---|---|---|
| 构成事实 | 82 | 董事会规模/席位、哪些或多少董事独立、有哪些委员会、谁在委员会任职或任主席、对委员会成员独立性/资格的认定 |
| 构成政策或流程 | 51 | 独立性标准、投票标准、提名与候选人标准、评估、更新换届、兼任上限 |
| 委员会或董事会职能 | 19 | 委员会或职位做什么——职责、权限、开会方式 |
| **不属于董事会构成** | **94** | 高管或董事薪酬（含"Audit Committee Chair Retainer"这类薪酬表行名）、审计师服务与独立性、股权计划条文、内幕交易与关联交易程序、股东沟通、履历里的他公司委员会、只有标签没有内容的块、其他治理话题（如 AI） |

**只有最后一类决定缺陷**。中间两类是否属于 C02，取决于"委员会信息"读得多宽——那是口径问题，这里只记录、不计为错误。每个值至少含三条最后一类（Paramount FY2025 三条，Salesforce 十九条）。

## 为什么会这样（量出来的）

冻结的选择器 `text_business_candidates.board_composition_candidates` 给一个块贴"委员会信息"标签的条件是：块里任意位置出现任一委员会名称，且任意位置出现任一 `committee_structure` 词（'chair of'、'members of'、'committee chair'、'serves as'、'member of'……）。两者不要求有关系，也不要求说的是本董事会。94 条里 **87 条**是这个标签放进来的；触发词前五位是 'chair of' 20、'members of' 18、'committee chair' 13、'serves as' 9、'member of' 8。选择器字节被 issue_28 各世代冻结、与普通路线共用，所以普通路线的 C02 有同样的行为——#47 是继承。

## 判读如何被约束

`tools/read_c02_board_statements.py` 经路线自己的文本输入与候选构建器、在当前代码下从已保存的代理材料重推每个位置的选择，要求判读**逐块、逐文本**描述这个选择，否则拒绝出结论（`JUDGEMENTS_DO_NOT_DESCRIBE_THE_SELECTION`）。所以判读绑定的是今天的路线从今天的字节选出的东西，而不是某次运行的记忆。`tests/vnext/test_c02_board_reading.py` 重推整份阅读并检查两种拒绝。

## 没有读、没有做

- **漏选方向没有读**：每个值已经含有定义之外的文本，不论另一方向如何都不能接受，所以没有花力气去找选择器漏掉的构成陈述。修复时这一方向必须补读。
- **没有修**：修复是一个后继选择器，而它的目标一部分是口径问题（上面两类中间项）。此前写"任何口径下都在外面的 94 条可以不等那个答案就去掉"——**这句按 246 条判读量过之后收回**（`deterministic-narrowing.json`，由同目录 `measure_deterministic_narrowing.py` 产出）：关键词选择器能表达的规则里，最好的组合（金额、薪酬用语、过短的标签块、简历里"某机构的董事会"与"（since 年份）"列出的机构）只去掉 94 条里的 39 条，还丢掉 2 条构成事实（"9 of 10 Director nominees are independent"、"9 out of 11 members of the Board are independent."）。剩下 55 条与构成事实共享冻结标签的表面特征（15 条简历摘录里，按简历实际写法写的三种模式合计只抓到 3 条，其中"某机构的董事"那一条还带走 1 条构成事实，所以没进组合）：简历里"另一家公司的审计委员会委员"和"本董事会审计委员会委员"用的是同样的词。所以去掉 94 条的规则不是关键词规则，**修法取决于口径**：选 1（只收构成事实）就写一个直接选构成事实的后继（董事会规模与独立性计数语句、委员会成员与主席指定），82 条判读是它的正例、另外 164 条是反例；选 2、3 则关键词收窄仍会带着任何口径下都不属于的摘录，逐条语义审阅是新调用类型、要模型额度。
- **判读者就是写路线的人**，这不是独立审阅。

## 待决口径（需要所有者）

C02 的"委员会信息"是否包括 (a) 委员会职能与运作（19 条）、(b) 构成政策与流程（51 条）？三个选项：

1. **只收构成事实**（82 条那一类）：与"董事人数、独立董事数、委员会信息"的字面最接近，也最容易机械化；
2. **构成事实 + 政策流程**：把"董事会怎么组成"也算进来；
3. **构成事实 + 政策流程 + 委员会职能**：最宽的读法。

推荐 1：定义列出的两项都是数，第三项与它们并列时读作"委员会构成信息"最自然；而且 2、3 会把每份代理材料里大段的治理程序说明收进来，值会变成一份"公司治理节选"而不是"董事会构成"。不论选哪个，94 条都在外面。

**82 条不是完整预期**（2026-09-26 审阅更正）：它们是**当前入选集合**里判为构成事实的正例。选择器从未选中的块没有读过，所以 82 条不能当作"应取集合"，也不能拿来说新规则漏没漏。选定口径后，写后继选择器之前必须补读漏选方向——各份代理材料里董事会与委员会章节中没被选中的块——把遗漏也判读出来；否则一个只在 246 条上校准的规则，会把"没被旧选择器选中"误当成"不属于构成事实"。推荐的口径表述：构成事实，含委员会的设置、成员、主席以及相关的独立性与资格认定（即上面第 1 项）。
