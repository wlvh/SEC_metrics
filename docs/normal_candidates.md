# 普通保存来源候选

此开发入口从已保存的实际SEC材料自动准备输入、执行受支持的原生候选并冻结记录。它不获取新材料、不调用模型，也不修改正式结果。资料限制和程序缺口逐坐标保留；一个失败不抹掉其他成功。

```bash
python3 tools/vnext_normal_candidate.py --output-root /absolute/new/external/directory
```

默认检查十家公司当前A03/A04/A09/A11/A12/A13、B06、C02/C03/C04、D01/D02。可重复使用`--company <配置ID>`或`--metric <ID>`限定开发验证范围。输出目录必须全新、在源码外，并且不属于现有正式发布目录；已有批次不覆盖。每个坐标记录原生Run、真实期间、结果状态和错误；summary.json给出完整请求集合和实际结果。退出码0只表示所请求的候选均已生成，2表示有候选缺口，不表示Issue完整验收。

数值与文本通过同一Projector生成既有20字段矩阵行和18字段证据行。文本保留完整原文、换行、申报日期与字节定位，状态为TEXT_QUAL；C02的申报日期不代表董事会测量日期。数值使用ratio/USD/flag，不推定概率或擅自换算显示单位；季度平均、时点与全年期间分别保留。WITHHELD保留空值和原因，非正权益B06保留权益证据并明确没有计算有效比值。展示规则与执行Spec分别绑定，执行过的Spec不因公共行适配而重写。这些行仍不是完整发布包。

V12/issue_28_v11已产生实际冻结记录，其规则和五文件不再同版本改写；未进行正式激活。新入口使用后继V13/issue_28_v12。V13公共验证入口先核验唯一安装规格、完整来源集合与实际期间，再处理具体数值或文本；换成旧规格不能跳过来源重建。
